# Практическая работа №1. Декомпозиция макета

## 1. Страницы
| № | URL / экран | Назначение | Основные блоки |
|---|---|---|---|
| 1 | Каталог | Показать набор карточек мероприятий (название, дата, места). Строка поиска, сортировка, фильтры и панель фильтрации. Добавление в "избранное". Обновление посредством фильтрации. Для пустого результата необходимо предусмотреть отдельное состояние «ничего не найдено» | Карточки с мероприятиями. Фильтр по назначению (Frontend, Backend и тд). Строка поиска. Фильтр по дате создания карточки мероприятия. Кнопка сброса фильтров до состояния "по умолчанию". Отображение количества мероприятий. Дополнительная фильтрация по дате, формату и уровню. Панель для переключения между страницами с мероприятиями. |
| 2 | Страница мероприятия | Отображение названия, категории, краткого описания, даты, места проведения и сведения об организаторе. Разделение контента на вкладки "Описание", "Программа", "Спикеры". Предусмотреть кнопки "Записаться", "В избранное". Пользователь должен иметь возможность вернуться в каталог. Кнопка записи должна иметь состояния default, loading, success и disabled, если
свободных мест нет. | Кнопка возврата к каталогу. Название мероприятия. Полное описание мероприятия. Программа мероприятия. Спикеры мероприятия. Кнопка "Записаться" на мероприятие. Кнопка "В избранное", чтобы добавить мероприятие в избранное. Название руководителя мероприятия. |
| 3 | Форма регистрации | Поля: имя и фамилия, e-mail, группа/команда, формат участия, комментарий, согласие
с правилами. Имя, e-mail, формат участия и согласие являются обязательными. Для некорректного e-mail показать локальную ошибку рядом с полем. Во время отправки блокировать повторное нажатие и показывать loading-состояние. После успешной отправки показать подтверждение и переход в раздел «Мои
события». |  |
